Slip through three moonlit rooms as a thief on the hunt for the Moonstone. Read raycast vision cones, manage suspicion, use the shadows beyond the gallery lamplight, and draw patrols away with noise and limited pebble lures before escaping with the relic and optional treasure.

## Controls

- Move with **WASD** or the **arrow keys**.
- Hold **Shift** to sneak quietly through the manor.
- Click a spot to throw a pebble lure and draw a nearby guard to investigate.

## Run it

Open [`game/index.html`](game/index.html) in a desktop browser to play. With the screenshots in place, run `node main.ts` with Node 22 to copy the game and screenshots into `MAKEFUN_OUTPUT_DIR` (or `/output`) and build `dossier.json`.
